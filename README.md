# CNC 工程師工具包

純前端(HTML / CSS / JavaScript)嘅 CNC 加工計算器合集,無需安裝任何依賴,直接用瀏覽器打開 `index.html` 即可使用。

## 設定、多語言與主題

- **設定面板**(側欄「⚙️ 設定」):語言同單位系統集中管理
- **六種語言**:繁體中文、简体中文、English、Deutsch、Français、हिन्दी(包括材料名稱同刀具建議知識庫全文翻譯)
- **公制 / 英制單位**:mm↔inch、m/min↔SFM、cm³/min↔in³/min、kW↔HP、N·m↔lbf·ft、µm↔µin、MPa↔ksi;切換時已輸入嘅數值會自動換算,內部計算一律以公制進行
- **日間 / 夜間模式**:側欄切換按鈕,預設跟隨系統偏好
- 語言、單位、主題選擇會儲存喺 localStorage,下次打開自動套用

## 匯出截圖

每個分頁右上角有「📸 匯出截圖」掣,會將當前面板嘅輸入參數、計算結果、表格同備註繪製成一張 PNG(跟隨當前主題配色):

- **手機**(iOS / Android):行系統分享面板,可以直接存入相簿或者傳畀同事
- **電腦**:直接下載 PNG 檔案

截圖引擎用原生 Canvas 繪製,無任何外部依賴,離線可用。

## 使用方法

```bash
# 直接打開(單機用,冇離線安裝)
open index.html

# 起個本地伺服器(離線安裝 PWA 需要行 http)
python3 -m http.server 8000
# 然後瀏覽 http://localhost:8000
```

## 離線安裝(PWA)

透過 **http/https**(本地伺服器或任何主機)打開時,會自動註冊 Service Worker 快取全部資源,可離線使用:

- **手機**:Chrome/Safari 揀「加到主畫面」,之後似 App 一樣全螢幕開啟,無網路都用得
- **電腦**:Chrome/Edge 網址列右邊嘅「安裝」圖示,裝成獨立視窗程式
- **離線**:首次載入後,關網路都照用(計算全部喺前端,無需伺服器)

> ⚠️ 直接 `file://` 打開唔會啟用離線快取(瀏覽器限制),但所有計算功能一樣正常。
> 改咗任何 `js/`、`css/` 或 `index.html` 之後,把 [sw.js](sw.js) 最上面嘅 `CACHE` 版本號 +1(例 `v1`→`v2`),使用者下次開啟就會更新快取。

## 內建材料庫

涵蓋 ISO 513 六大群組共 16 種常用材料:

- **P(鋼)**:S45C、SCM440、SKD11(退火)
- **M(不鏽鋼)**:SUS304、SUS316L、17-4PH
- **K(鑄鐵)**:FC250、FCD450
- **N(非鐵)**:6061-T6、7075-T6、黃銅、紫銅
- **S(耐熱合金)**:Ti-6Al-4V、Inconel 718
- **H(淬硬鋼)**:HRC 48–55、HRC 56–62

每種材料含建議切削速度範圍、單位切削力 kc1.1、切屑厚度指數 mc、進給係數。

## 主要公式

- 轉速:n = 1000·vc / (π·D)
- 銑削進給:vf = n·z·fz;MRR:Q = ap·ae·vf / 1000
- 切削功率:Pc = Q·kc / 60000,kc = kc1.1 · hm^(−mc)
- 理論粗糙度:Ra ≈ f² / (32·rε);Rz ≈ f² / (8·rε)
- 切屑變薄:RCTF = 1 / √(1 − (1 − 2·ae/D)²)
- Taylor 刀具壽命:vc·Tⁿ = C(硬質合金 n≈0.25)
- 攻牙底孔:切削攻牙 = D − P;擠壓攻牙 ≈ D − P/2(英制 UNC/UNF 以 P = 25.4/TPI 代入;NPT 錐管牙用標準底孔查表)
- 材料重量:W (kg) = 體積 (cm³) × 密度 (g/cm³) / 1000;成本 = W × 每 kg 單價
- 鑽尖長度:L = (D/2) / tan(鑽尖角 / 2);通孔貫穿深 = 孔深 + L
- 啄鑽 (G83):啄鑽次數 = ⌈孔深 / q⌉;循環時間 = 進給時間 + 退屑回程(快移)時間
- 插補進給補償:中心圓 D_c = 目標圓 ∓ 刀徑(內圓−、外圓+);補償係數 K = D_c / D_圓;程式進給 = 目標刃口進給 × K

## 免責聲明

所有建議值僅供起始參考,實際加工請依刀具商目錄、機床剛性同夾持狀況修正。

## 檔案結構

```
index.html            頁面結構
css/style.css         深色/淺色主題樣式
js/i18n.js            六語言字典(UI 文字、材料名、刀具建議知識庫)
js/data.js            材料庫、硬度表、螺紋規格、產品目錄
js/calc.js            計算核心(純函式,一律公制)
js/export.js          截圖匯出引擎(Canvas 繪製 + Web Share / 下載)
js/shop.js            銷售:情境產品卡 + 詢價單
js/app.js             UI 互動邏輯(i18n、主題、單位系統、計算綁定)
manifest.webmanifest  PWA 資訊清單(名稱、圖示、主題色)
sw.js                 Service Worker(離線快取 app shell)
icon-192/512.png      PWA 圖示;apple-touch-icon.png  iOS 主畫面圖示
```

新增語言:喺 `js/i18n.js` 複製一個語言區塊(例如 `en`),改 key 同翻譯內容即可,語言選單會自動出現。
